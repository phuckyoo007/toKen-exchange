Welcome

Set up your wallet to get started.

This is the standalone website version of Token Exchange. It encrypts your wallet and stores it only in this browser (nowhere else) -- but a website is an easier target for phishing/DNS/lookalike-domain tricks than an installed browser extension, which is why MetaMask and similar wallets don't ship a key-holding website at all. If you're not sure which to use: the browser extension version of Token Exchange is the safer default for everyday use; this site is here for when an extension truly isn't an option. See this page's README for the full explanation before trusting it with real funds.

Buy crypto

Buy is powered by MoonPay, a separate third-party service -- Token Exchange never touches your payment details.

Already hold some crypto? Skip MoonPay entirely -- swap it for what you need directly on-chain, no third party, no signup.

MoonPay opens right here, below. Since this wallet can't safely sign requests with a secret key (that must never live inside a browser extension -- see lib/buy-config.js), paste in your receiving address yourself once it loads:

MoonPay opens right here, below, with your receiving address already filled in -- nothing to paste.

Sell for cash

Sell is powered by MoonPay, the same third-party service Buy uses -- Token Exchange never touches your payout details.

MoonPay opens right here, below, and quotes you a cash payout. It will show you a deposit address to send your crypto to -- once MoonPay receives it, it converts and pays out to your linked bank account or card.

Come back here and use Send with the address MoonPay gives you -- this wallet never sends funds anywhere on its own.

Import private key

This adds a separate account to this wallet from a raw private key, not from your recovery phrase -- back it up on its own, since your recovery phrase won't restore it. Never share a private key with anyone; anyone who has it can spend everything in that account.

Add watch-only address

Tracks an address's balance, tokens and activity without holding a key for it -- there's nothing here to sign with, so Send and Swap stay off for it. Useful for keeping an eye on a cold-storage or hardware-wallet address from here.
